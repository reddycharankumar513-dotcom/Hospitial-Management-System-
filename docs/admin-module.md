# Smart Hospital Operations Center (Admin Module)

## 1. Overview
The Admin Operations Center (`/admin/dashboard`) acts as the central command node for hospital monitoring, resource management, and administrative control.

## 2. Key Modules
- **Operations Dashboard**: Real-time KPI cards, registration trends, department caseload, bed occupancy breakdown.
- **User Management**: Staff account creation, credential resets, role assignments, active/inactive toggles.
- **Role Permission Matrix**: Granular View/Create/Update/Delete permissions for 10 hospital resources.
- **Visual Bed Map**: Interactive ward grid (ICU, General, Private, Emergency) with live status indicators.
- **Audit Logs**: Immutable telemetric log viewer capturing user actions, resources, correlation IDs, and IP addresses.
- **System Settings**: Configurable hospital parameters, appointment slot durations, and pharmacy reorder thresholds.
